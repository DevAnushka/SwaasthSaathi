## Open Source Productivity & DevTools
- [playwright-cli](https://github.com/microsoft/playwright-cli) - Microsoft's CLI for Playwright actions, with skills for coding agents. Apache-2.0, actively maintained
- [Graphify](https://github.com/Graphify-Labs/graphify) - Turns a codebase (plus docs, SQL, configs, PDFs) into a queryable knowledge graph via local tree-sitter AST - no LLM, no embeddings for code. Every edge labelled `EXTRACTED` or `INFERRED` so you can tell fact from inference
- [basemode](https://github.com/ChristopherKahler/base) - Rust CLI that builds a workspace knowledge graph and injects the relevant slice into each Claude Code turn. **PolyForm Noncommercial - commercial use needs a separate licence**, so check before it touches a paid product
